# Avinash Bhat — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or run a simple local server from this folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Before publishing

Update these placeholders in `index.html`:

- `hello@example.com` with your real public contact email.
- `https://www.linkedin.com/` with your actual LinkedIn profile URL.
- The experience dates / employment wording marked `VERIFY DATES`.
- The internship dates and title to match your resume.
- Generic GitHub profile links on projects with their exact repository URLs.
- Verify the technologies under each project and the skills list reflect what you can confidently discuss.
- Add your resume PDF in this folder (for example `assets/Avinash_Bhat_Resume.pdf`) and add a visible download link if desired.

The site uses Google Fonts (Inter and Fira Code) when online and falls back to system fonts when offline.
